# Sentiment Analysis with IndoBERT and Recurrent Neural Networks

## Project Overview
This project focuses on sentiment analysis for Indonesian text using the IndoNLU dataset's `smsa_doc-sentiment-prosa` subset. The goal is to classify text into 'positive', 'negative', or 'neutral' sentiments. We explore different deep learning architectures, including a baseline IndoBERT model, IndoBERT combined with a Simple RNN, and IndoBERT combined with an LSTM, to compare their performance.

## 1. Data Download
The dataset used in this project is part of the IndoNLU benchmark. It is downloaded directly from its GitHub repository using `git clone` and `git sparse-checkout`. This process retrieves only the necessary data subset for sentiment analysis.

## 2. Data Loading and Initial Inspection
The sentiment analysis dataset consists of training, validation, and test sets, which are stored in TSV (Tab Separated Values) files. These files are loaded into pandas DataFrames. Initially, there was a challenge where the first row was incorrectly interpreted as data, so the loading process was adjusted to properly assign column headers ('text', 'label').

## 3. Exploratory Data Analysis (EDA)
Exploratory Data Analysis was conducted to understand the characteristics of the dataset. This involved examining the distribution of sentiment labels ('positive', 'negative', 'neutral') across the training and validation datasets. Visualizations such as bar plots were used to illustrate these distributions, revealing a significant class imbalance where 'positive' was the most frequent sentiment and 'neutral' was the least frequent.

## 4. Data Preprocessing
Data preprocessing was a crucial step to prepare the text data for model training. It involved three main sub-steps:

### Text Cleaning
A custom function was developed to clean the raw text data. This function performed several operations including converting all text to lowercase, removing URLs, eliminating non-alphanumeric characters, and standardizing whitespace.

### Label Encoding
To facilitate machine learning, the categorical sentiment labels ('negative', 'neutral', 'positive') were converted into numerical representations (0, 1, 2) respectively.

### Random Oversampling
To address the class imbalance identified during EDA, Random Oversampling was applied to the training data. This technique duplicates samples from the minority classes ('negative' and 'neutral') until all sentiment classes have an equal number of samples, matching the count of the majority class ('positive'). After oversampling, each class in the training set contained 6416 samples, leading to a total of 19248 training samples.

## 5. Tokenization and Data Loaders
The cleaned and preprocessed text data underwent tokenization using the `BertTokenizer` from the `huggingface/transformers` library, specifically utilizing the `indobenchmark/indobert-base-p1` pre-trained model. A utility function was created to manage batch tokenization, ensuring proper padding, truncation, and conversion to PyTorch tensors. Subsequently, `TensorDataset` and `DataLoader` from PyTorch were employed to efficiently manage the datasets, creating iterable batches for training and evaluation. A batch size of 16 was used, and the computational device (GPU or CPU) was configured.

## 6. Model Architectures
Three distinct deep learning models were developed and evaluated, all built upon the `indobenchmark/indobert-base-p1` pre-trained BERT model:

### 6.1. IndoBERT + RNN (`IndoBertRNN`)
This architecture integrates the BERT encoder with a simple PyTorch Recurrent Neural Network (RNN) layer. The sequential output from the BERT model is passed into the RNN, and the final hidden state of the RNN is then used for the sentiment classification task.

### 6.2. IndoBERT + LSTM (`IndoBertLSTM`)
Similar to the RNN variant, this model employs a Long Short-Term Memory (LSTM) layer subsequent to the BERT encoder. The final hidden state generated by the LSTM is fed into a fully connected layer to make the sentiment prediction.

### 6.3. IndoBERT Baseline (`IndoBertBaseline`)
This model serves as a straightforward baseline. It directly uses the embedding of the `[CLS]` token (a special token used by BERT for classification tasks) from the BERT output for sentiment classification, without incorporating any additional recurrent layers. This model helps in understanding the performance gain contributed by the RNN or LSTM layers.

All models incorporate a dropout layer for regularization and a final linear layer to classify text into the three sentiment categories.

## 7. Model Training
A dedicated `train_model` function was implemented to manage the training and validation process. The training utilizes `nn.CrossEntropyLoss` as the loss function and `torch.optim.Adam` as the optimizer. Progress bars (`tqdm`) were integrated to monitor training progress per epoch. Each model was trained for 3 epochs with a learning rate of `2e-5`. The training function tracked and reported the average training loss and validation accuracy for each epoch. After training, plots comparing the training loss and validation accuracy across the three models were generated to visualize their learning curves.

## 8. Model Evaluation
Upon completion of training, each model's performance was rigorously assessed on the unseen test dataset. The evaluation metrics included classification reports, which provide precision, recall, and F1-score for each class, and confusion matrices, which visually illustrate the model's ability to correctly classify each sentiment. An `evaluate_model` function was used to generate predictions on the test set. Finally, the overall accuracy of each model was calculated and compared using a bar plot, providing a clear summary of their performance.

**Key Findings:**
- The IndoBERT+LSTM model achieved the highest accuracy, suggesting that the LSTM layer effectively captured important sequential dependencies in the Indonesian text, leading to superior sentiment classification compared to the simpler RNN and the BERT baseline models.
- The classification reports provided detailed insights into how well each model performed on 'negative', 'neutral', and 'positive' sentiments, highlighting their strengths and weaknesses.
